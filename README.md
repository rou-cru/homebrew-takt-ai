# Rou-cru Takt-ai

## How do I install these formulae?

`brew install rou-cru/takt-ai/<formula>`

Or `brew tap rou-cru/takt-ai` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "rou-cru/takt-ai"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
